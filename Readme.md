# Helsinki Eco Adventure 🌱
A simple text-based game made with Python.

## Objectives 🎯
Explore Helsinki, collect litter, and recycle it correctly.
Earn 50 points and become a Helsinki Eco Hero! ♻️🌱

## What is the game?
You play as an Eco Explorer.
Explore places around Helsinki.
Find and collect litter.
Put the litter in the correct recycling bin.
Earn points and eco-coins.
Get 50 points to win!

## Places
Forest 🌲
Lake 🌊
Park 🌳
Beach 🏖️

## Game Features
-Recycling system ♻️
-Random events
-Health system 
-Achievements 🏆
-Map
## Save and load game
Win and Game Over screens

## Files
main.py – starts the game
game.py – controls the game
player.py – stores player information
locations.py – game locations
items.py – recyclable items
events.py – random events
save_manager.py – saves and loads the game

## How to play
Run:
python main.py
Explore → Collect → Recycle → Earn 50 points → Win! 

## Message:
Good luck explorer!
